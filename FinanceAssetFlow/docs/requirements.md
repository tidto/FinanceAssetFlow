# 요구사항 명세

## 1. 프로젝트 개요

- 프로젝트명: 개인 자산 관리 및 포트폴리오 매니저 (PFM)
- 개발 환경: Android Studio, Kotlin, Jetpack Compose
- 저장 방식: Room(SQLite) 기반 로컬 영속화
- 아키텍처: MVVM, StateFlow, Repository Pattern
- 목표: 오프라인에서도 동작하는 개인 자산 관리 앱을 구현하고, 금융 도메인 이해를 코드와 문서로 증명한다.

이 프로젝트는 개인의 자산, 부채, 순자산을 관리하고, 자산군 비중과 투자자산의 평가손익을 확인할 수 있는 단일 Android 앱이다. 백엔드 없이 로컬에서만 실행되며, 사용자가 별도 DB를 수기로 만들 필요 없이 Room이 앱 실행 시 테이블을 자동 생성한다.

## 2. 사용자 시나리오

1. 사용자는 앱을 실행하여 대시보드에서 총자산, 총부채, 순자산을 확인한다.
2. 사용자는 자산 등록 화면에서 자산명, 자산군, 매입 금액, 현재 평가 금액, 메모를 입력해 자산을 추가한다.
3. 사용자는 자산 상세 화면에서 현재 평가 금액을 수정하고, 수정 즉시 수익률과 대시보드 집계가 반영되는 것을 확인한다.
4. 사용자는 투자자산 비중이 과도할 때 리밸런싱 경고를 확인하고 포트폴리오 조정 방향을 참고한다.
5. 사용자는 만기된 예금이나 전량 매도한 자산을 삭제하거나 메모로 기록을 남겨 이력을 관리한다.

## 6. 진행 기록 원칙

앞으로 진행할 때마다 다음 규칙으로 기록한다.

1. 설계가 바뀌면 `docs/implementation_log.md`에 날짜, 변경 내용, 이유, 트레이드오프를 적는다.
2. 버그를 만나면 `docs/bugfix_log.md`에 재현 조건, 원인, 수정 내용, 회귀 방지 방법을 적는다.
3. 테스트를 실행하면 `docs/test_result.md`에 실행 명령과 결과를 누적한다.
4. 체크리스트는 `docs/checklist.md`에서 완료 여부를 갱신한다.
