# 초기 데이터 및 테스트 데이터 설계

## 1. 목적

초기 데이터는 앱 첫 실행 화면을 비어 있는 상태로만 보여주지 않고, 개인 자산 관리 앱의 핵심 기능을 빠르게 확인하기 위해 사용한다. 실제 배포 앱에서는 사용자가 직접 데이터를 입력하는 것이 기본이며, 과제 테스트 또는 데모 빌드에서만 샘플 데이터를 삽입한다.

## 2. Seed 데이터 삽입 정책

- RoomDatabase.Callback 또는 Repository 초기화 로직에서 최초 1회 삽입한다.
- 이미 `assets` 테이블에 데이터가 있으면 중복 삽입하지 않는다.
- 테스트에서는 인메모리 Room DB를 사용하여 동일한 Seed 데이터 삽입 여부를 검증한다.
