Agentic Coding 기반 Android Native 앱 과제

Kotlin + Jetpack Compose 단일 Android 앱 개발 과제 (주제 자유)

본 과제는 Agent(예: AI 코딩 에이전트)와 협업하여, 실제 개발 프로젝트 수준의 기획·설계·구현·테스트·기록을 수행하는 것을 목표로 한다.

기준 규모는 ./inventory 프로젝트 수준으로 하며, 코드뿐 아니라 과정 추적 문서를 반드시 제출해야 한다.

1. 개발 범위

  • 플랫폼: Android Native (Kotlin + Jetpack Compose)
  • 주제: 자유 (예: 생활 관리, 학습 도구, 일정/메모, 취미 기록, 헬스케어 등)
  • 규모: ./inventory와 유사한 중소형 앱 (다중 화면, CRUD, 상태관리, 로컬 데이터 또는 원격 저장 포함. 원격에 데이터를 저장할 경우 백엔드 또는 데이터베이스가 최종 성적 공시일 까지 배포 유지해야 함.)
  • 필수: 오프라인에서도 핵심 기능 동작

권장 MVVM, Room, Navigation, Material 3 Compose, Hilt

2. 필수 기능 요구사항

ID요구사항필수
F-01핵심 엔티티 1종 이상에 대해 생성/조회/수정/삭제(CRUD) 제공O
F-02최소 3개 이상의 주요 화면 구성 (목록/상세/등록·수정 등)O
F-03입력 검증 및 예외 처리(UI 피드백) 제공O
F-04저장소(Room 등의 로컬 또는 원격 저장소) 기반 데이터 영속화O
F-05Agent와 협업한 의사결정/수정 이력 문서화O

5. 테스트 요구사항

  • 단위 테스트 + UI(Compose) 테스트 포함
  • 핵심 비즈니스 로직 테스트 케이스 명시
  • 최소 1회 이상 전체 테스트 실행 결과 기록
  • 정적 분석 결과(예: lint, detekt 등) 기록

6. 제출 형식

  • 프로젝트 루트: 실행 가능한 Android 프로젝트 전체
  • 문서 폴더: docs/ (3번 항목 파일 필수 포함)
  • README: README.md 실행 방법, 빌드 방법, 테스트 실행 방법, 앱 개요
  • 압축 파일명: 학번_이름_agentic_android.zip

8. 최소 기준

  • 앱 실행 가능
  • 핵심 CRUD + 화면 이동 + 저장소 연동 동작
  • docs/ 필수 문서 누락 없음
  • 테스트 계획 문서와 실제 실행 기록 존재
